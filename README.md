# Hiboo 🦉

> AI agent copilot that helps you land the right job.

Hiboo compares a job offer with your profile, scores the fit, finds evidence
in your past projects and highlights the skills you're missing.

🚧 **Work in progress** : first release planned for end of November 2026.

## Tech stack

Python 3.12 · uv · ruff · pytest :  more to come as the project grows.

## Development

```bash
cp .env.example .env
docker compose up -d
uv sync
uv run pytest
```
